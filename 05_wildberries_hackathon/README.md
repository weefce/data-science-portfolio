# Прогнозирование объёмов отгрузок со складов (Wildberries)

## Описание проекта

Прогнозирование объёмов отгрузок со складов на 8 шагов вперёд (шаг 30 минут). Задача решается с помощью методов машинного обучения для временных рядов

## Бизнес-задача

Снизить простои и дефицит транспорта, сократить издержки на автопарк, обеспечить стабильную работу складов в пиковые периоды

## Ключевые результаты

- **Лучшая модель:** Ridge регрессия, обученная на последних 7 днях
- **Скор на публичном лидерборде:** `0.3365`
- **Скор на приватном лидерборде:** `0.3349`

## Метрика

Метрика соревнования: `WAPE + |Relative Bias|`

WAPE = Σ|y_true - y_pred| / Σy_true

Relative Bias = | Σy_pred / Σy_true - 1 |

- **WAPE** - средняя ошибка в процентах с весами
- **Relative Bias** - показывает, насколько модель систематически завышает или занижает прогноз

## Ключевые выводы

- **Данные шумные** - простые статистические модели (SARIMA) неэффективны
- **Лучший результат дало окно в 7 дней** - более старые данные только ухудшают качество
- **Ridge показал лучший результат** - линейная модель оказалась стабильнее XGBoost на этих данных

## Технологии

- **Библиотеки:** pandas, numpy, matplotlib, seaborn, scikit-learn
- **Методы:** скользящее окно, OneHotEncoding, StandardScaler, Pipeline
- **Модели:** Ridge, Lasso, RandomForest, XGBoost

## Особенности подхода

### 1. Данные
- 4.6 млн строк, 1000 маршрутов
- Целевая переменная - объём отгрузок за последний час
- Нужно предсказать 8 будущих значений для каждого маршрута

### 2. Предобработка
- Генерация будущих таргетов (`target_step_1`...`target_step_8`)
- Добавлены базовые признаки: лаги статусов, суммы, час, день недели

### 3. Валидация
- Для проверки качества использовались последние 8 строк каждого маршрута
- Перебирались окна в 7, 14 и 21 день
