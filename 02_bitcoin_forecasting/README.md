# Прогнозирование цены биткоина на 7 дней

## Описание проекта
Сравнительный анализ статистических моделей и ML-подходов для прогнозирования цены биткоина. Основное внимание уделяется корректной обработке временных рядов и предотвращению утечки данных

## Бизнес задача
Построение краткосрочного прогноза цены биткоина на 7 дней. Для оценки качества используется MAE метрика , показывающая ошибку в долларах 

## Ключевые результаты
- **Лучшая модель:** Holt-Winters (mul-mul)
- **MAE 7 дней:** 389 (1,4 % от средней цены)
- **MAE 14 дней:** 807 (3 %)
- **MAE 30 дней:** 2870 (10,6 %)

Статистические модели превосходят наивный прогноз (повтор последней цены)
ML-модели показали ошибку в 10 раз больше - из-за ограничений на утечку данных (использовались только лаги >= 7 дней) они не смогли уловить значимые закономерности

## Ключевые выводы
- **Сезонность** - слабо выражена, но её учёт улучшает прогноз на 7 дней
- **Автокорреляция** - биткоин сильно зависит от вчерашней цены (lag_1 = 0,99), однако лаги старше недели не несут полезной информации.-
- **Утечка данных** - в условиях строгого разделения данных ML-подход с лагами оказывается неэффективным для данного ряда
- **Статистические модели** - Holt-Winters показывает лучшие результаты благодаря учёту структуры временного ряда
- **Деградация точности** - с увеличением горизонта ошибка растёт экспоненциально (1,4 % - 3 % - 10,6 %)

## Технологии 
- **Библиотеки:** pandas, numpy, matplotlib, seaborn, statsmodels, pmdarima, prophet, scikit-learn, xgboost
- **Методы:** ADF-тест, сезонное разложение, ACF/PACF анализ, TimeSeriesSplit, GridSearchCV
- **Модели:** Exponential Smoothing (Holt, Holt-Winters), ARIMA/SARIMA, Prophet, Linear Regression, Ridge, Lasso, XGBoost

## Особенности подхода 

### 1. Предобработка
- Признак Volume приведён к числовому типу (K/M/B - числа)
- Для визуализации объёма использована логарифмическая шкала

### 2. Разделение данных
- Train: первые 510 дней
- Test: последние 30 дней (горизонты 7, 14, 30 дней)

### 3. Статистические модели
- **Naive baseline** - последняя цена (MAE 7 = 467)
- **Holt** - линейный тренд (MAE 7 = 450)
- **Holt-Winters** - с учётом сезонности (MAE 7 = 389) - лучшая
- **ARIMA(1,1,1)** - ручной подбор (MAE 7 = 468)
- **auto_arima** - авто-подбор (MAE 7 = 473)
- **Prophet** - линейный тренд (MAE 7 = 557)

### 4. ML-подход
- Лаги только с 7-го дня (чтобы избежать утечки)
- Временные признаки: месяц, день недели, выходной
- Модели: Linear Regression, Ridge, Lasso, XGBoost
- **Результат:** MAE > 3900 - в 10 раз хуже наивного прогноза

### 5. Ключевое ограничение
Из-за защиты от утечки использовались только лаги >= 7 дней. Для биткоина, который хорошо предсказывается по вчерашней цене (lag_1), это сделало ML-подход бесполезным

## Основные этапы работы 
1. Загрузка и предобработка данных - преобразование типов, обработка Volume
2. EDA временных рядов - анализ трендов, сезонности, стационарности (ADF-тест), ACF/PACF
3. Разделение на train/test с тремя горизонтами (7, 14, 30 дней)
4. Статистические модели - Exponential Smoothing, ARIMA/SARIMA, Prophet
5. ML подход - Feature Engineering с лагами >= 7 дней, обучение моделей
6. Сравнительный анализ - выбор лучшей модели по MAE
